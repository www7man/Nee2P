# FastFile — оптическая передача файлов (decimen)

Передача файлов между двумя устройствами **только через экран и камеру** — без
сети, без установки приложений, без спаривания. Файл летит как свет: одно
устройство показывает непрерывный поток QR-кодов, второе снимает их камерой и
собирает файл обратно.

Папка встроена в Nee2P как отдельная кнопка **FastFile** на главном экране.

## Файлы

- `sender.html` — отправитель (~57 KB). Самодостаточная страница, ноль внешних
  зависимостей. Выбирает файл и показывает поток кодов.
- `receiver.html` — приёмник (~1.3 MB, больше, потому что содержит встроенный
  WASM-декодер `zxing-cpp` и decode-worker как base64). Открывает камеру и
  собирает файл.

Оба файла раздаются сервером Nee2P как статика по путям
`/fastfile/sender.html` и `/fastfile/receiver.html` (см. раздачу статики в
`server.js`).

## Как это работает

Вместо того чтобы слать блоки файла по порядку (одна потерянная рамка — и ждём
целый круг), отправитель передаёт XOR псевдослучайного подмножества блоков —
**Luby transform (LT) coding**, фонтанный код. Приёмнику нужно собрать примерно
`K·1.15` уникальных кадров в любом порядке и «отшелушить» файл. Потерянные
кадры стоят только времени, но не корректности — частоты кадров отправителя и
приёмника не обязаны совпадать.

Каждая рамка несёт 20-байтный заголовок (ID сессии, порядковый номер, число и
размер блоков, длина файла, хэш), поэтому приёмник может зацепиться за поток в
любой момент. До 64 MB на файл, имя и MIME сохраняются в потоке. Перед выдачей
файла приёмник сверяет данные по SHA-256.

## Модель безопасности (важно)

Decimen **не шифрует** данные. Как сказано в README апстрима: «даваемое
свойство — отсутствие сети, а не конфиденциальность». Любой, кто наведёт камеру
на экран отправителя, сможет прочитать данные. Это намеренно отличается от
криптомодели Nee2P (X25519 + ML-KEM-768 + AES-256-GCM): FastFile — это способ
передать файл по полностью офлайн-каналу, а не секретный канал.

## Обновление

1. Скачать свежие standalone из
   <https://github.com/bashalarmistalt/decimen-optical-transfer/releases> (ищи
   `decimen-<tag>-sender.html` и `decimen-<tag>-receiver.html`).
2. Сверить SHA-256 с `SHA256SUMS.txt` из того же релиза.
3. Положить поверх `sender.html` / `receiver.html` и обновить версию в этом
   README.
